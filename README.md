Autonomous web application pentest orchestrator featuring 16 security modules, Burp/ZAP REST integration, and LLM AI mode.

---

## 🌟 Key Features

- ⚔️ **Single-Command Orchestration**: Executes 16 automated security modules across target web applications.
- 🔌 **Burp Suite & OWASP ZAP Integration**: REST API drivers controlling enterprise security scanners.
- 🤖 **LLM AI Mode**: Intelligent exploit payload generation and false-positive filtering.
- 📄 **11 Report Formats**: Generates executive PDF, Markdown, JSON, and HTML vulnerability reports.

## 🚀 Quick Start

### Prerequisites
- Python 3.9+ / Node.js (depending on module)
- Git

### Installation
```bash
# Clone repository
git clone https://github.com/sohan-a11y/pentora.git
cd pentora

# Install dependencies (if python project)
pip install -r requirements.txt
```
